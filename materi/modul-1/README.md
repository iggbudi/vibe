# Modul 1 — Memulai dari Nol

**Durasi**: 3 minggu
**Tujuan modul**: Membangun aplikasi baru dari halaman kosong dengan bantuan AI — dari ide mentah sampai aplikasi yang berfungsi, tersimpan rapi di git.

## Daftar Lesson
| # | Lesson | Fokus |
|---|---|---|
| 1.1 | [Spesifikasi dari ide](01-spesifikasi.md) | Menerjemahkan ide menjadi requirement yang bisa dibaca AI |
| 1.2 | [Generate struktur project](02-struktur-project.md) | Prompt pertama: skeleton aplikasi |
| 1.3 | [Menjalankan & debugging](03-debugging.md) | Siklus run → error → perbaiki |
| 1.4 | [Iterasi fitur & UX](04-iterasi.md) | Menambah fitur incremental dengan aman |
| 1.5 | [Version control & dokumentasi](05-git-dokumentasi.md) | Git dasar + README |

## Proyek Akhir Modul
**Aplikasi "Todo list + catatan pribadi"** dengan kriteria:
- (a) Jalan tanpa error
- (b) Data persisten setelah restart (database SQLite / file JSON)
- (c) README jelas (cara install, cara pakai)
- (d) History git rapi (commit per fitur)

## Prasyarat
- Modul 0 selesai (tools terinstall, paham prompt dasar, lingkungan kerja siap)
- Sudah tahu: apa itu vibe coding, struktur prompt (konteks → instruksi → constraints → acceptance criteria)
