# Modul 0 — Fondasi Vibe Coding

**Durasi**: 1 minggu
**Tujuan modul**: Memahami paradigma vibe coding (bukan sekadar "minta AI buatkan kode") dan menyiapkan lingkungan kerja yang benar.

## Daftar Lesson
| # | Lesson | Fokus |
|---|---|---|
| 0.1 | [Apa itu Vibe Coding](01-apa-itu-vibe-coding.md) | Definisi, sejarah, kapan tepat digunakan |
| 0.2 | [Ekosistem tools](02-ekosistem-tools.md) | Assistant vs agent vs IDE, cara kerja LLM |
| 0.3 | [Setup lingkungan](03-setup-lingkungan.md) | Terminal, runtime, git, agent coding |
| 0.4 | [Etika & keamanan](04-etika-keamanan.md) | Review kode AI, secret, risiko nyata |
| 0.5 | [Menulis prompt efektif](05-prompt-efektif.md) | Struktur prompt yang menghasilkan output berkualitas |

## Praktikum Akhir Modul
1. Semua tools terinstall & terkonfigurasi (ceklist di 0.3)
2. Tulis **5 prompt percobaan** ke AI untuk tugas coding kecil
3. Evaluasi kualitas tiap output dengan rubrik 0.5
4. Perbaiki prompt berdasarkan evaluasi → bandingkan hasilnya

## Prasyarat
- Bisa mengoperasikan komputer/HP (buka aplikasi, install, internet)
- Paham konsep file & folder
- **Tidak perlu** pengalaman coding — modul ini dirancang untuk pemula total

## Filosofi modul ini
Vibe coding bukan "AI ajaib mengerjakan semuanya". Ini kerja sama: **kamu sebagai pengarah (konteks, arah, verifikasi), AI sebagai pelaksana (generate, refactor, debug)**. Modul 0 membangun dua sisi itu: paham tools-nya, dan paham cara mengarahkannya.
