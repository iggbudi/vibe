# Capstone — Project Akhir

**Durasi**: 1 minggu
**Tujuan**: Membuktikan penguasaan seluruh kurikulum — dari ide, membangun, mengintegrasikan, sampai mendokumentasikan — dalam satu project nyata.

## Aturan main

1. **Semua kode boleh dibantu AI** — itu inti kurikulum ini. Yang dinilai adalah *cara kamu mengarahkan dan memverifikasi*, bukan jumlah baris yang kamu ketik.
2. **Kamu harus bisa menjelaskan semuanya** — jika tidak bisa menjelaskan cara kerja bagian tertentu, berarti itu bukan bagianmu.
3. **Gunakan pola dari semua modul**: prompt terstruktur (0.5), iterasi & git rapi (1.5), konteks codebase (2.2), keamanan secret (0.4), error handling (3.5 & 4.5).
4. **Kerjakan sendiri** — capstone bukan latihan berkelompok.

## Pilihan Project (pilih 1)

| # | Pilihan | Untuk siapa |
|---|---|---|
| **A** | Bangun aplikasi baru: 3+ fitur inti + minimal 1 integrasi third-party | Yang mau buktikan "bisa dari nol" |
| **B** | Ambil project open-source di GitHub → tambah fitur meaningful → buka Pull Request | Yang mau pengalaman kontribusi nyata |
| **C** | Chatbot multi-fungsi: otomasi + analitik untuk kebutuhan nyata | Yang mau bot yang benar-benar dipakai |

Detail lengkap: [01-pilihan-proyek.md](01-pilihan-proyek.md)

## Deliverable (yang dikumpulkan)

1. **Repo GitHub** rapi — README, struktur jelas, git history bermakna
2. **Demo video** ±5 menit — masalah → solusi → cara kerja → tantangan
3. **Refleksi tertulis** — prompt paling sukses, kegagalan & cara mengatasinya

Detail lengkap: [02-deliverable.md](02-deliverable.md)

| Presentasi (demo video + menjelaskan) | 20% |
