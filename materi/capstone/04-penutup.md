# Penutup — Setelah Capstone

Selamat sudah sampai di akhir! 🎓 Ini bukan akhir perjalanan, tapi awal pola kerja yang baru. Berikut peta untuk melanjutkan.

## Yang sudah kamu kuasai

| Keterampilan | Bukti |
|---|---|
| Mengarahkan AI dengan prompt terstruktur | Modul 0.5 + jurnal prompt |
| Membangun dari nol dengan iterasi sehat | Modul 1 + proyek capstone |
| Bekerja di codebase orang lain | Modul 2 + (pilihan B: PR nyata) |
| Chatbot yang benar-benar bekerja | Modul 3 + capstone C |
| Integrasi & ketahanan aplikasi | Modul 4 + chaos test |
| Keamanan: secret, review, verifikasi | Tersebar di semua modul |

## Pola yang harus terus dipakai

1. **Prompt 4 bagian** (konteks → instruksi → constraints → acceptance criteria) — setiap kali minta AI
2. **Verifikasi selalu** — AI bilang "selesai" ≠ selesai. Jalankan, tes, tanya edge case
3. **Failing test dulu** — untuk bug & perubahan berisiko
4. **Commit per fitur** — git history adalah dokumentasi terbaikmu & jaring pengamanmu
5. **Secret di .env** — selamanya, tanpa pengecualian
6. **Koreksi >2x = mulai sesi baru** — jangan bertahan di konteks yang kotor

## Roadmap lanjutan (pilih sesuai minat)

### 🧠 Lebih dalam tentang AI & kode
- **Agentic workflows**: multi-agent (writer/reviewer), agent teams, subagents untuk tugas terpisah
- **Evaluasi kode AI**: tooling review otomatis, security scanning, testing strategi
- **Fine-tuning / prompt engineering lanjutan**: chain-of-thought, few-shot

### 🚀 Skala & deployment
- **Deploy**: dari Termux/laptop ke VPS/cloud (Docker, serverless, CI/CD)
- **Database skala**: PostgreSQL lanjutan, index, migration tools (Alembic)
- **Monitoring**: observability penuh (log aggregation, alerting, tracing)

### 🤖 Chatbot tingkat lanjut
- **RAG penuh**: vector database, chunking pintar, evaluasi retrieval quality
- **Multi-platform**: bot yang jalan di Telegram + WhatsApp + web sekaligus
- **Voice**: asisten suara (speech-to-text + text-to-speech)

### 💼 Profesional
- **Portfolio**: 2-3 project capstone-level di GitHub dengan README profesional
- **Kontribusi open source** berkelanjutan (pilihan B bisa jadi awal karir)
- **Kolaborasi tim**: code review AI, workflow pair programming dengan AI

## Tiga kebiasaan terakhir

1. **Buat project kecil setiap minggu** — 1-2 hari, fitur sederhana, selesai. Ini menjaga "vibe" tetap tajam tanpa beban besar.
2. **Tulis jurnal prompt** — terus catat prompt yang berhasil/gagal. Pola pribadimu adalah aset terbaik.
3. **Review kode lamamu** — buka project Modul 1 dalam 3 bulan; perbaiki dengan skill barumu. Perbandingan itu menunjukkan pertumbuhanmu.

## Kata penutup

Karpathy menyebut vibe coding sebagai "fully give in to the vibes" — tapi kurikulum ini mengajarkan versi yang lebih matang: **beri AI kekuatan menulis, jangan pernah lepaskan tanggung jawab memahami.** Itulah perbedaan antara "menyalin kode ajaib" dan "membangun software".

> *"If an LLM wrote every line of your code, but you've reviewed, tested, and understood it all — that's not vibe coding, that's using an LLM as a typing assistant."* — Simon Willison

Kamu sekarang punya asisten mengetik terbaik di dunia, dan kemampuan untuk mengarahkannya. 🚀
